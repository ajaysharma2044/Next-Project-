# The Next Chapter Project — Version 2

A static, privacy-first educational website. Open `index.html` locally to preview.

## New in V2
- Three 3-question knowledge checks (one per lesson), scored only in the browser
- Savings goal calculator (no account or server)
- Six-item financial independence checklist (session only)
- Pilot/feedback and impact-measurement transparency section

## Publish updates to the SAME Netlify site
1. Sign in to Netlify and open your existing project `the-next-chapter-project`.
2. Open **Deploys**.
3. Drag this unzipped `next-chapter-project-v2` folder into the manual deploy drop zone.
4. Wait for the deploy to finish and refresh your existing site.

Don't create a new Netlify project unless you want a separate URL.

## Privacy and accuracy
No account, database, tracking, or analytics. All inputs and quiz answers are handled locally in the browser. No visitor responses are aggregated or stored. Content is general educational information, not individualized financial advice. Review content with a qualified educator before running youth pilots.
